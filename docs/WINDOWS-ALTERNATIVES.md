# Existing Windows alternatives

Research checked 11 November 2026 against the developers' download/features pages. These are desktop downloads; browser-only and mobile-only products are excluded from the recommendations. Feature claims below are documented capabilities, not hands-on verification of the downloaded programs.

| Application and official download | Free features | Paid features / limitations | Match for this request |
|---|---|---|---|
| [DesignDoll](https://www.terawell.net/en/page-download.php) | No-expiry free Windows version: poseable bodies, model colors, lighting/effects, image creation, importing external models | Pro is listed at US$79 once; adds loading saved TWD scenes, OBJ export and downloading Doll Atelier models | Strongest documented free full-body option. I could not verify a built-in Asaro + sphere set, independently colored shadow fill, or calculated surface-bounce transport. Could import a suitable head. |
| [Study Buddy](https://flotasser.itch.io/study-buddy) | Free Windows EXE; head reference, light rotation, focal length, resizable always-on-top window | No paid tier identified on the download page | Simple head/perspective reference. Creator lists human head and skull; a built-in planar Asaro head, sphere, light RGB/intensity and bounce calculations are not verified. |
| [Simple Model Poser](https://writinwater.itch.io/simple-model-poser) | Windows ZIP, free / optional donation; poseable mannequin, movable light, camera controls, image saving | No feature paywall advertised | Basic full-body fallback. The developer explicitly calls it bare-bones; no documented Asaro head, sphere, independently colored fill or bounce-light engine. Choose the downloadable Windows ZIP, not its web demo. |
| [Colour Constructor 2](https://colourconstructor.com/) | No free tier found | US$10; standalone Windows/macOS app with sphere types, Asaro preview, material palettes and light controls | Closest named sphere/Asaro color-study product, but fails the free requirement. Its documentation describes image masks and compositing, so it does not establish freely rotated, geometric ray-traced lighting of those previews. |

The lack of verified features is not proof those features are absent. No exact free desktop match was confirmed in this search. That is why Shading Help was implemented, rather than claiming that no such software could exist.

## Excluded because of your platform requirements

[PoseMy.Art's install page](https://posemy.art/download/) describes a Chrome-installed web app and explicitly requires an internet connection. [Magic Poser's download page](https://magicposer.com/download.html) lists iOS and Android. [Light Dropper](https://www.lightdropper.com/) describes its browser-based experience. These are not recommended here as native Windows/offline solutions.
